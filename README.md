## The pitch

> Introducing QueueBuddy: an app that finds the longest line in your city, reserves your spot in it, and livestreams strangers standing still so you can feel productive while achieving absolutely nothing, anywhere, anytime.

(221 characters.)

## How it works

`main.py` is deterministic and uses no network. It writes the single
sentence above to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
